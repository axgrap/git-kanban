Help & Keyboard Shortcuts

How to Use

  • Drag & Drop: Click and drag cards between columns to move tickets
  • Claim/Unclaim: Double-click a card to claim or unclaim ownership
  • Save: Click "Save & Commit" to write changes to README.md and create a git commit
  • Owner Info: Owners are determined from git blame history (commits with "kanban:" prefix)

Keyboard Shortcuts

  • Ctrl+S: Save and commit
  • Ctrl+R / F5: Reload board
  • ?: Show this help
  • Tab: Navigate between cards
  • Enter: Select/activate focused card

Accessibility

This interface supports keyboard navigation and screen readers. Use Tab to navigate, Enter to select, and Escape to cancel.
